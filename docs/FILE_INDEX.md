# File Index

- `include/Behavior.h`: abstract behavior interface.
- `include/Vector2D.h`: small 2D math helper.
- `include/*.h`: public C++ headers.
- `src/*.cpp`: C++ implementation files.
- `src/main.cpp`: executable entry point.
- `scripts/build.bat`, `scripts/build.sh`, `CMakeLists.txt`: build helpers.
- `scripts/build-raylib.bat`, `scripts/build-raylib.sh`: optional raylib build helpers.
- `docs/RAYLIB_SETUP.md`: where to put raylib and how to run the native graphics build.
- `docs/PROJECT_SETUP_GUIDE.md`: general guide for C++ project structure and dependency setup.
- `third_party/`: optional local dependency folder.
